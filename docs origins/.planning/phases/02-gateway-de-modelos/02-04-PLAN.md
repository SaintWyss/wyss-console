<objective>
Implementar el gate de presupuesto (GATE-04) y el store de traces (GATE-05). CostTracker.authorize() veta con BudgetExceeded ANTES de cada llamada (pre-autorización, no reporte) contra presupuesto global + por-agente; el costo se calcula local determinísticamente (D-24). TraceStore es una DB SQLite separada (traces.db) que replica el patrón WAL fail-fast de audit pero sin triggers append-only (traces expiran a 90d, D-22).

Purpose: El gate es la única defensa real contra el denial-of-wallet — un presupuesto que solo registra después de la llamada es advisory, no enforced (Pitfall 2). El tracing da observabilidad consultable separada de la auditoría.
Output: `src/gateway/{traces_schema,traces,cost}.py`, tests de traces y del gate de costo.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gateway → traces.db | DB SQLite separada de audit.db y datos de usuario (D-22); permisos de archivo local |
| caller → CostTracker.authorize | El gate veta antes de gastar; sin override por chat/agente (regla #6) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-budget-bypass | Denial of Service | CostTracker.authorize | mitigate | Gate hard-stop pre-autorización: BudgetExceeded ANTES de la llamada; test verifica que el provider nunca se invoca al exceder (Pitfall 2, D-18) |
| T-02-budget-advisory | Denial of Service | costo del provider | mitigate | Costo calculado LOCAL (tokens × precio config); el gate nunca depende del costo reportado por el provider (D-24) |
| T-02-trace-pii | Information Disclosure | traces.db (prompts completos) | accept | traces.db separada con permisos de archivo local; prompt guardado es POST-minimizer (sin secretos); retención 90d default (D-22). Riesgo aceptado: archivo local en ext4 del owner |
| T-02-budget-override | Tampering/Repudiation | destrabe de presupuesto | mitigate | Destrabe solo editando config.toml + reload; sin override por chat ni comando de agente (D-19, regla #6) — fuera de scope de runtime aquí, garantizado por ausencia de API de mutación |
| T-02-trace-wal | Tampering | traces.db sobre NTFS | mitigate | Smoke test WAL fail-fast replicado de audit (Pitfall 6); data_dir debe estar en ext4, no en mount NTFS |
</threat_model>
