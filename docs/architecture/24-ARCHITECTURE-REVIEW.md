The set, challenged. This document looks for what is wrong, contradictory, unproven or missing
in documents 01 to 23. It was written by the author of the set, after the set, by re-reading
04, 05, 07 to 11, 14, 19, 21 and 22 in full and the code named in each finding. **It is a
self-review and does not replace an independent one** (§14).

The list of things to look for came from the owner's brief, which reached the author cut off
after the tenth item ("False…"). Item §12 is the author's reading of that fragment: false
claims of state, of hot reload and of completion.

## 1. Result in short

Fifty-two numbered findings, RV-01 to RV-53 (RV-15 is not used; it was merged into RV-01).
None of them invalidates the direction (two planes, the provider's file as the truth, read
before write). Six of them would have caused a wrong implementation if a phase had been
planned from the documents as they stood:

| RV-03   | One ordering of the write race loses the provider's own change silently, and the "microseconds" were never measured            | F2a                                    |
| RV-04   | A running session was marked as `using` a change on the strength of documentation alone                                        | F2a (corrected in 07, 08, 09)          |

## 16. Residual risks if every resolution above is adopted

1. A process of the same user, or a compromised page with a terminal, can do everything the
   Console can do, without it. No design at this level of privilege changes that.
2. A provider can change how it reads, reloads or rewrites its files in any release. Every
   mutation is tied to a verified version (CTL-26), which makes the feature unavailable after
   each provider update until the evidence is renewed. That is a maintenance cost with no end.
3. A secret the classifier does not recognise, wherever the classifier is trusted.
4. The check-then-rename interval, narrowed and detected, not closed.
5. A user who confirms a native dialog without reading it.
6. Configuration removed on a computer where the Console is not running is seen only later, and
   under DN-18's recommendation cannot be restored from this computer.
