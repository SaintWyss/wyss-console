### DN-02 — How the Console starts an agent in a terminal

| Field                        | Content                                                                                                                                                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Question                     | By what mechanism does a start from the catalogue become a running agent in a PTY?                                                                                                                                        |
| Status                       | Proposed; needs an ADR extending ADRs 0005 to 0007. Its contract is drafted in 05 §17 (2026-10-13): request, generated files, recipes, identity check, and the checklist the ADR must state. Drafting decides nothing     |
| Alternatives                 | Through the user's interactive shell, which replaces itself with the agent · spawn the agent directly · type the command into a running shell                                                                             |

## 5. Who decides what

| Kind of decision                                          | Decider                                                    |
| --------------------------------------------------------- | ---------------------------------------------------------- |
| Product goals; trade-offs of security against convenience | The owner                                                  |
| A change to an accepted security guarantee                | The owner, by an ADR, with evidence and an external review |
| Technical choices inside a phase that change no contract  | The builder, stated in the phase's report                  |
| Whether a phase starts                                    | The owner                                                  |
| Whether evidence is sufficient                            | A reviewer who did not build it, then the owner            |
