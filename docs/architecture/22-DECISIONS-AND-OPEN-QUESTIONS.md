# 22 — Decisions and open questions

Everything this set leaves undecided or unverified, in one place. A **decision needed** (DN) is
a choice someone has to make; an **open question** (OQ) is a fact someone has to find out.
Neither blocks anything until the phase named beside it.

## 4. Assumptions this set makes

If one is false, the sections that depend on it change.

| #   | Assumption                                                                         | Depends on it                         |
| --- | ---------------------------------------------------------------------------------- | ------------------------------------- |
| AS1 | Providers keep documenting their configuration files as user-editable              | The whole of 07                       |
| AS2 | A rename within one directory is atomic on the filesystems in use                  | 07 §5.4, 14 §4                        |
| AS3 | inotify reports changes on the filesystems where the owner keeps his configuration | 07 §7                                 |
| AS4 | The user's session has a `systemd --user` manager                                  | The authority; a future host service  |
| AS5 | One user per machine session: no hostile second user with access to the home       | 11, as ADR 0018 already assumes `[R]` |
| AS6 | Provider documentation read on 2026-10-12 describes the installed versions         | 06 §3                                 |
| AS7 | The owner remains the only decider of security trade-offs on his machines          | 10 §5.4                               |

## 5. Who decides what

| Kind of decision                                          | Decider                                                    |
| --------------------------------------------------------- | ---------------------------------------------------------- |
| Product goals; trade-offs of security against convenience | The owner                                                  |
| A change to an accepted security guarantee                | The owner, by an ADR, with evidence and an external review |
| Technical choices inside a phase that change no contract  | The builder, stated in the phase's report                  |
| Whether a phase starts                                    | The owner                                                  |
| Whether evidence is sufficient                            | A reviewer who did not build it, then the owner            |
