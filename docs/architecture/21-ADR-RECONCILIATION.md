# 21 — ADR reconciliation

ADRs 0001 to 0028 against the complete design of this set. ADR 0028 already holds a
compatibility matrix for its own decision (`0028`, section "Compatibility with ADRs 0001 to
0027") `[R]`; this document goes further: it looks at every later phase too, and says which new
ADRs the roadmap needs. **No ADR is changed by this set.** Where one should change, the change
is listed in §4 as a decision to take.

Basis of reading: the sections listed in ADR 0028 (`0028`, paragraph "Read directly for this
matrix") `[R]`, re-used; plus, for this set, ADR 0002 `:28-73`, 0005 `:47-56`, 0008 `:78-100`,
0012 `:104-131`, 0015 `:40-62` and `:134-148`, 0016 `:36-66`, 0018 `:110-127`, 0026 `:26-60`
and 0027 in full. The long ADRs (0017, 0018, 0021, 0023, 0025) were not re-read line by line.

## 3. Where this set finds ADR 0028 itself in need of a decision

1. **Restoration data and ADR 0003.** ADR 0028 classes ADR 0003 as "superseded in one area"
   and says restoration data "may still hold a secret" (`0028`, section 7 and the row for 0003)
   `[R]`. The owner has since said this is not to be read as permission to keep secrets, and
   asked for the alternatives to be compared before anything is built. This set did that
   ([11 §5](11-SECURITY-THREAT-MODEL.md)) and recommends a narrower rule: use the provider's
   own state where it exists; keep only entries a classifier finds free of secrets; refuse the
   rest. Under that rule ADR 0003's sentence needs no exception for secrets, and ADR 0028's
   supersession would be withdrawn or narrowed. **ADR 0028 is accepted and is not edited
   here.** The change belongs to a new ADR (proposed number 0029) once the owner decides DN-01.
   Until then F2a may not start, and nothing that may hold a secret is persisted.
2. **The phrase "by removal".** ADR 0028 §3 lets Claude Code hooks be disabled by taking the
   entry out and keeping it elsewhere. Item 1 limits what "kept" may mean; nothing else
   changes.
3. Nothing else in ADR 0028 was found to conflict with this set.

## 5. What must never be done to reconcile documents

- An accepted ADR is not rewritten to look as if it had foreseen a later decision.
- A security guarantee is not relaxed because a newer document reads more conveniently
  without it (D10).
- A sentence of an ADR that no longer holds is named, with the place where it stops holding
  and the decision that ended it. ADR 0028 does this for four sentences; this document adds
  the ones that later phases will end (§1, last column).
