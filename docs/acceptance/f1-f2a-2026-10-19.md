# Acceptance evidence: F1 and F2a, 2026-10-19

What was run, on what, and what it showed. The owner's own acceptance (the AC lines that
need his files or his word) is marked as such and has not been given.

## Environment

- The desktop built in debug (`target/debug/wyss-console`), its window served by Vite, in a
  nested KWin Wayland session with Xwayland (`:77`), a session bus of its own, and
  `XDG_STATE_HOME`, `XDG_DATA_HOME`, `XDG_CONFIG_HOME` and `XDG_CACHE_HOME` in a private
  directory. Input by `xdotool`, screenshots by `import`.
- F1, reading: `HOME` was the owner's real home, so the inventory read his real
  configuration; nothing was clicked that plans a change. His files were not written:
  `~/.claude/settings.json`, `~/.codex/config.toml`, `hooks.json` and `AGENTS.md` still carry
  their modification time from 2026-10-18 22:01, and the real
  `~/.local/state/wyss-console/configuration` was never created (the state of this run was in
  the private directory).
- F2a, changing: `HOME` was a temporary directory with a synthetic `~/.claude/settings.json`
  (two hooks in one group, one with a fake token in its command, one `Stop` hook) and a
  skill. No real provider file was changed.

## Defects found by running it, and fixed

- A missing Secret Service looked like an empty one (`secret-tool` exits 1 for both), so a
  plan promised encryption that could not happen. The apply was already safe; the plan is now
  truthful, and a test holds it.
- The details of a selected item opened below a list of hundreds of items. They open above it
  and the view goes back to the top.

## Not done, said plainly

- The happy path with a real wallet in the GUI (creating the wallet, applying, putting the
  hook back) was not clicked through; it is covered by the tests and by the real Secret
  Service test above.
- Selecting a project from the Configuration view is not wired to the folder dialog.
- Codex mutations (F2b), MCP changes and creating or editing entries are not implemented.
- The external review that F1 and F2a require has not been run.
