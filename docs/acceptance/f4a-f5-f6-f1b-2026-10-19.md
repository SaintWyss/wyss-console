## Limits, stated

- Authoring covers Claude Code hooks and OpenCode MCP servers. Codex needs a table-creating TOML
  editor that does not exist; rule files and import templates are not built.
- A managed model **choice** and the acceptance of `model/rerouted` are not built (ADR 0043).
- A comment sitting between two entries makes removing either refuse, rather than move or lose it.
- The page-side forms were tested with a fake desktop; the native windows are in the GUI record
  below.

## In the real window (nested display, release build, 2026-10-19)

directories of its own with synthetic fixtures, a private session bus and a throw-away keyring.

`~/.claude/settings.json`, `~/.codex/config.toml` and `~/.config/opencode/opencode.jsonc` had the same
hash before and after both. The owner's own keyring daemon wrote its file during the run (its own
log shows a periodic client, at 18:36:04, 18:36:41 and 18:37:26); the vault key of the run went to
