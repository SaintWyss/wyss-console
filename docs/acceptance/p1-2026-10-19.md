# P1: real-environment measurements, partial

2026-10-19, `saint-acer`, CachyOS KDE Wayland, kernel 6.18.55-2-cachyos-lts.
The installed Wyss Console 0.2.0 release, its existing protocol-1 host and one idle fish
terminal were measured in the owner's actual desktop. No HOME/XDG/bus/keyring isolation,
container, cache drop, package installation or change to the owner's other applications.

Ghostty was **already installed**: `/usr/bin/ghostty`, pacman package `ghostty 1.3.1-2.2`,
CLI version `1.3.1-arch2.2`, GTK runtime 4.24.1 and OpenGL renderer. The earlier statement
that comparison required installing it is obsolete. A separate real Ghostty window was
opened with its own normal idle fish; no agent or model was started in it.

## Method and boundaries

`benchmarks/idle.py` reads `/proc` process times and `smaps_rollup` once per second for
five minutes. It records monotonic time, executable SHA-256, PID/start identity, raw CPU,
RSS, PSS and swap. It refuses PID reuse and does not report CPU for a changing helper set.
UI plus WebKit, the independent host, authority root and reference root are separate.
The shells and native agents are excluded. Raw samples remain under `.artifacts/acceptance/`.

These are **single observations**, not canonical P1 acceptance. Other user applications
remained open; packaging/compilation ran during parts of the observations. Visibility,
occlusion and cursor settings were not controlled. The first run also included opening
the Ghostty reference. The full authority runtime tree is not included in its root figure.
PSS must be read with swap: several processes had substantial swapped-out memory, so low
resident PSS cannot be treated as their complete memory cost.

The first five-minute run and a second five-minute concurrent reference run are recorded
by their exact executable hashes. The later template GUI update is not silently substituted
for the binary actually measured. The sampler's one-second validation run is not a baseline.

## Concurrent five-minute observation

301 samples, 300 seconds; all recorded process identities and helper sets stayed stable.
CPU is percentage of **one core**. Memory columns are MiB. Swap is reported separately
and is not proportional swap; it must not be silently added to PSS as a budget result.

| Bucket              | Mean CPU | Median resident PSS | Median swap |
| ------------------- | -------: | ------------------: | ----------: |
| Wyss UI + WebKit    |   1.117% |               78.42 |      130.29 |
| Wyss host           |   0.673% |                0.97 |        7.78 |
| Authority root only |   0.007% |                1.85 |        2.65 |
| Ghostty root only   |   0.247% |               15.64 |      107.93 |

The UI and host together averaged **1.790% of one core** in this observation. These
numbers do not establish a comparative performance budget: memory pressure, swapped
pages, background work, visibility and cursor settings were not controlled. Ghostty's
shell and the Console's shell are outside these figures. No native agent ran under the
host; its per-agent overhead is **NOT_RUN**, not zero.

Raw records: `p1-2026-10-19-idle.json`, `p1-2026-10-19-comparison.json` and the separate
one-second `p1-2026-10-19-sampler-check.json` under `.artifacts/acceptance/`. The latest
sampler also records RSS and proportional swap; the earlier long runs retain their
original RSS/PSS/swap samples. No samples were removed or substituted.

## Still required for full P1

Canonical repetitions (three sessions, repeated five-minute windows); controlled shown/
hidden observations; cold/warm exec-to-drawn-prompt timings; per-terminal empty/5,000-line
memory growth; native agent overhead separately; key-to-drawn-glyph and render latency;
BC-01 to BC-05 throughput and event gaps; divider dragging/resize; reconnect and full host/
authority overhead. Bootstrap confidence intervals and budgets require those observations.
No provisional performance budget is declared passed and P1 remains open.
