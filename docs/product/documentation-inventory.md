## Search boundary

Only repository-tracked artifacts and new documentation were considered. Untracked personal
drafts, ignored acceptance artifacts, provider homes, credentials, external attachments and
unavailable private/public web pages are not represented as inspected. Local-only evidence
cited by a report remains an explicit reproducibility limitation, not fabricated content.
