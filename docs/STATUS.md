## Independent limits

- **Managed F8 capacity is one.** Higher fixture limits do not change production
  admission. Native delegation has its own policy (default two, maximum eight);
  it is a different subsystem and does not increase F8 capacity.
- P1 and F8/P2 have distinct links and stores. A shell P1 status does not prove
  F8 readiness. The ordinary GUI path does not select F8 without its argument.
- Native full access, delegated Native workers, restricted B1 candidates,
  Managed profiles, planners and strong human approval are different trust
  contracts. Same-account UI confirmation does not resist arbitrary same-UID
  or privileged account compromise.
- Accepted Local Tools residual risks include provider credential exposure to
  an explicitly approved command and pre-existing workspace hardlinks.
- Configured, provider-resolved, session-observed and actually used are
  different states. Unknown observations remain unknown.

## Resource and acceptance gaps

The [resource contract](contracts/f8/resources.json) is executable input. Source
ceilings and clock-injected tests do not establish hard OS deadlines or a whole
process-tree memory boundary. The source reconciliation confirms or retains these specific gaps; static source
checks do not reproduce runtime timing or provider behavior:

| Area                | Remaining issue                                                                                                                                                                                                                                            |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Provider scratch    | Aligned: stdout and stderr are read through one 4096-byte `process_worker::PROVIDER_SCRATCH`, held to `provider_scratch_bytes` by a test and classified as enforced. A source bound on read size only; real-provider timing and memory remain unqualified. |
| Service timing      | A nominal poll cadence does not prove the 50 ms service guarantee under load.                                                                                                                                                                              |
| Catalogue           | The F8 snapshot path enforces 50 models; classifier labels, completeness and concurrent allocation costs need reconciliation.                                                                                                                              |
| Streams/attachments | A global eight-turn retention bound is not a per-runtime fairness proof; distinct F8 attachment-count enforcement remains unproven.                                                                                                                        |
| Memory and refresh  | RSS diagnostics are soft, not hard descendant-tree limits; real-provider multi-process credential refresh and contention remain unqualified.                                                                                                               |

Remaining whole-product acceptance also includes reference-PC latency/idle/load
budgets, source-to-installed-binary correspondence, protected writer/snapshot
conditions, recovery, accessibility, real providers and actual Android hardware.
Historical documentation-review PASS results do not close these product gates.

V10 schema support and the guarded protocol extension are now documented in

inventory path before claiming complete FP-NFR-01 acceptance.
