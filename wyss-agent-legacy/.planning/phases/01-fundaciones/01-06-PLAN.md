<config_spec>
<!-- Esqueleto — RESEARCH §"Config: tomllib + Pydantic fail-fast" (líneas 606-640). -->

- `class DenyRuleModel(BaseModel)`: `model_config = ConfigDict(extra="forbid")`; mapea las claves del TOML de ejemplo (id, match_action, match_target) a los campos de `DenyRule`.
- `class PolicyConfigModel(BaseModel)`: `model_config = ConfigDict(extra="forbid")`; campos `file_count_b/c`, `dir_count_c`, `delete_count_d` (int con defaults), `sensitive_dirs: list[str]`, `deny: list[DenyRuleModel] = []`.
- `class WyssConfigModel(BaseModel)`: `model_config = ConfigDict(extra="forbid", frozen=True)`; `data_dir: Path`, `audit_db: Path`, `policy: PolicyConfigModel = PolicyConfigModel()`.
- `load_settings(path: Path) -> WyssSettings`:
  - `tomllib.load` → `WyssConfigModel.model_validate(raw)`.
  - `FileNotFoundError` → mensaje "no existe el archivo de configuración: {path}".
  - `tomllib.TOMLDecodeError` → "TOML inválido en {path}: {e}".
  - `ValidationError` → líneas por error con `'.'.join(loc)` + msg, prefijo "configuración inválida en {path}".
  - éxito → `_to_settings(model)`: construye `PolicyRules(deny=BUILTIN_DENY + tuple(config_deny), base_levels=<defaults docs/13>, thresholds=AggregateThresholds(file_count_b=..., ...))` y retorna `WyssSettings(data_dir, audit_db, policy)`.
- Decisión de diseño para "fail-fast con error legible": PREFERIR levantar una excepción de dominio (`WyssError` o subclase) con el mensaje legible (testeable con pytest.raises sin matar el proceso), y dejar el `sys.exit` al caller CLI de Fase 5. Anotar esta decisión en el SUMMARY.
</config_spec>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06-T | Tampering | config.toml parsing | mitigate | `extra="forbid"` en todos los modelos → un typo en una deny rule aborta el boot (fail-closed); error nombra el campo (loc) |
| T-01-06-EoP | Elevation of Privilege | denylist desde config | mitigate | `PolicyRules.deny = BUILTIN_DENY + config`; sin ruta para remover built-ins (regla #2); test lo verifica |
| T-01-06-DoS | Denial of Service | config inexistente/mal formada | mitigate | FileNotFoundError/TOMLDecodeError → mensaje accionable, no traceback crudo |
