Flujo (RESEARCH Architecture diagram): por cada SourceFile pending/resumable:
1. secret_filter.check_path → si match: mark_excluded_secret + AuditEvent, continue (NO abrir)
2. resolve extractor por media_type; si None → mark_skipped(skipped_unsupported)
3. extract → buffer temporal (texto NO persiste aún)
4. secret_filter.check_content(text) → si match: mark_excluded_secret + AuditEvent, continue (texto del buffer descartado, NUNCA toca el índice)
5. si text vacío (Pitfall 6) → mark_extracted sin chunkear
6. chunk → fts_index.upsert(IndexEntry...) → mark_extracted (commit)
7. si embedder disponible: embed(chunk texts) → vector_index.upsert → mark_embedded; si Ollama down (httpx error) → log + dejar extracted (D-32)
Errores de extract (ExtractionError) → mark_failed + continue (D-36). UnsupportedFileError → mark_skipped(skipped_unsupported).
Errores sistémicos (DB inaccesible, root inexistente) → propagar (abortan, D-36).

estimate() (RESEARCH Code Examples): recorre el filesystem con stat-only (sin extraer), proyecta
chunks (~total_bytes / (512*4)), embed_time_s (~chunks*0.002), cost_usd=0.0 (Ollama local, D-34).
dry_run(): lista qué se indexaría y por qué (nuevo/modificado) sin tocar nada (D-37).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| archivos no confiables (2TB) → pipeline → índice | El pipeline es el último punto donde un secreto puede ser bloqueado antes de persistir al índice (regla #8) |
| embedder (Ollama localhost) → pipeline | Servicio externo que puede caer; su caída no debe abortar ni perder progreso |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-21 | Information Disclosure | secreto que llega al índice | mitigate | El secret_filter corre ANTES de fts/vector; el texto vive en variable local y se descarta ante match; prueba dirigida end-to-end (test_planted_secret_not_indexed, criterio 4) lo verifica contra FTS5 y Chroma |
| T-03-22 | Repudiation | exclusión de secreto sin rastro | mitigate | D-28/regla #1: cada exclusión genera un AuditEvent con path+pattern+layer (nunca el valor); test verifica el evento sin el secreto |
| T-03-23 | DoS | un archivo roto corta toda la corrida de 2TB | mitigate | D-36: ExtractionError → mark_failed + continue; solo errores sistémicos (DB/root) abortan |
| T-03-24 | Availability | Ollama caído pierde el progreso | mitigate | D-32: embed falla → archivo queda extracted (commit), re-run con Ollama vivo completa; la corrida no aborta |
| T-03-25 | Tampering | crash a mitad pierde estado | mitigate | KNOW-03: commit por archivo en el StateStore; crash-resume verificado |
</threat_model>
