<objective>
Implementar el routing determinístico (GATE-02) y los adaptadores de proveedor HTTP (GATE-01): ModelRouter resuelve tier→(provider, model_alias, max_tokens) sin LLM ni heurística (D-16); LiteLLMProvider (proxy OpenAI-compatible en localhost:4000), AnthropicProvider (Messages API directa) y OllamaEmbeddingProvider, todos con httpx directo. Los dicts de las APIs mueren dentro del adapter; afuera solo viaja dominio.

Purpose: Estos son los puntos de salida reales a IA externa. httpx directo (no SDKs) evita el doble-retry que descontrola el gate de presupuesto (Pitfall 1). El router determinístico garantiza que el caller declara el tier y el sistema nunca decide costo/calidad por su cuenta (filosofía humano-primero).
Output: `src/gateway/router.py`, `src/gateway/providers/{litellm,anthropic,ollama,fakes,__init__}.py`, tests de router/providers/embeddings.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gateway → LiteLLM/Anthropic (red) | httpx cruza a APIs externas; api_key/master_key viajan en headers, nunca en logs |
| gateway → Ollama (localhost) | Contenido personal a embeddings va a Ollama LOCAL — nunca sale de la máquina (D-15, V8) |
| caller → ModelRouter | El caller declara tier; el router nunca elige por heurística (D-16) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-tier-fallback | Tampering/Repudiation | ModelRouter.resolve | mitigate | Fail-fast sin fallback silencioso: tier inexistente → UnknownTier con tiers disponibles (D-17); test del error |
| T-02-double-retry | Denial of Service | providers httpx | mitigate | httpx directo sin retry interno; raise_for_status propaga; el retry centralizado vive en el gateway (02-05). Test: provider no reintenta en 4xx (Pitfall 1) |
| T-02-key-in-log | Information Disclosure | headers de provider | mitigate | api_key/master_key en headers desde env; nunca logueados ni en ModelResponse (V2/V7) |
| T-02-embed-egress | Information Disclosure | OllamaEmbeddingProvider | accept | Embeddings van a Ollama LOCAL (localhost:11434); contenido personal nunca sale (D-15, V8) — riesgo aceptado: localhost de confianza |
| T-02-sdk-type-leak | Tampering | adapters de provider | mitigate | El dict del JSON muere en el adapter; afuera solo ModelResponse/Vector de dominio (anti-pattern de research) |
</threat_model>
