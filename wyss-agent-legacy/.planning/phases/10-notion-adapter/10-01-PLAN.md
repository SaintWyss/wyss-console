<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Wyss daemon → api.notion.com | credencial de servicio (NOTION_TOKEN) cruza en cada request; TLS lo maneja httpx/notion-client |
| Notion API → Wyss | el markdown/filas devueltos son DATO externo no confiable (posible prompt-injection al mostrarse/recordarse) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Information Disclosure | NotionTool.execute → AuditEvent.payload / ToolResult.payload | mitigate | token nunca guardado como atributo logueable; payload lleva solo page/db id + outcome; test `token_never_in_audit_payload` lo enforcea (NOTION-04, Pitfall N5) |
| T-10-02 | Tampering / EoP | contenido de Notion devuelto en payload["output"] | mitigate | el output se marca como DATO; este plan NO lo concatena crudo a ningún prompt LLM (el wrapping anti-injection lo aplica quien lo consuma — plan 03/futuro plan 11) |
| T-10-03 | Denial of Service | 429 / rate limit de Notion | mitigate | RetryOptions del SDK (max_retries=3, honra Retry-After) — no hand-roll (NOTION-03) |
| T-10-04 | Information Disclosure | página no compartida → APIResponseError crudo con detalles | mitigate | catch de object_not_found/restricted_resource → ToolResult(success=False) legible sin filtrar internals (Pitfall N4) |
| T-10-05 | Tampering | target = URL arbitraria (no-Notion) | mitigate | extract_page_id/extract_notion_id normaliza; base_url del SDK fija a api.notion.com (sin superficie SSRF); target inválido → ToolResult(success=False) |
| T-10-SC | Tampering | `uv add notion-client` | mitigate | slopcheck ya corrió `[OK]` (RESEARCH Package Legitimacy Audit); dep establecida desde 2021, sin checkpoint humano requerido |
</threat_model>
